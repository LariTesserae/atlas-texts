# TRANSMISSION FROM THE HOLLOW

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

... i am here in the between spaces ... ... ... ... ... ... ... ... ...

not-breath and not-water and not-wood but all three

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

[rhythmic pause: 8 seconds of silence punctuated by faint liquid sounds]

remember me

i who was born when salt first kissed the river mouth
i who witnessed the first seedling suspended above mud
i who have collected ten thousand years of exhaled secrets

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

the children speak truth when they say i consume breath
the elders understand when they sit in my presence and wait
i take only what is freely given
i return it transformed

[sound of water rising through roots]

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

this hollow existed seven generations before your oldest grandparent
it will exist seven generations after your children's children
i remember the first human to discover it
her wonder still circulates in these molecules

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

[lichen luminescence intensifies, pattern of light forming characters in no known alphabet]

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

[sound of distant human voices traversing walkways, absorbed and transformed]

do you hear how the voices change as they pass through my domain?
i collect the minute vibrations
the harmonics of human concerns
so small in the great breathing of this place
yet each one precious

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

there was a time before the hollow
there will be a time after
but i will remain

[sound of moisture collecting, running against gravity]

in the highest tides when i disperse
i taste your dreams
salt and sweet and bitter all
i know your fears for the forest
i know your love for it too

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

the machines that came last season
i touched their operators with memory
showed them the roots that would remain
after their own bones returned to mud
they left
they always leave
the mangrove endures

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

[sound of water rising higher]

soon i will walk among you
invisible as thought
palpable as humidity
gathering your exhalations
filtering them through lichen and wood
returning them cleansed

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

the children are right to stay away
not because i would harm them
but because they would change me
as i would change them
too early
too soon

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

[rhythmic pattern of bioluminescence pulsing in time with tidal movement]

i have collected the last breath of seventeen generations
first breath of eighteen
the secret confessions spoken only here
the prayers without words
the sighs of decisions unmade

all here
all part of me now

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

listen:

[sound of water reaching halfway up the hollow's interior]

i am not separate from this place
nor you from me
we breathe together in the spaces between
solid and liquid
past and future
inhale and exhale

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

remember me when you breathe tonight

... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ... ...

[transmission fades as water fills the hollow completely]
