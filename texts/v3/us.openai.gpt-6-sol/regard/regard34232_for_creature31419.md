The power would come close enough to see the crack, and then it would stop.

It would see the shrimp clear a passage that the next tide would fill. It would see a tube worm add one more narrow rim to its shelf. It would see a young shell settle where, if it lived, two routes would become one. None of these creatures had asked for a city, and none could be kept safe without changing the city around it.

The power could smooth the stone, widen the passages, make sure plankton reached every mouth. But a widened passage would expose the amphipod beneath the shelf. A steady current would favor some feeders and starve others. To preserve the place exactly as it was would be to end the work by which it lived.

So it would leave the sharp edges sharp. It would let the tide carry food and grit, and let the shells close when an arm passed over them. At the far end, it would watch the pale seep cloud the water and settle.

If harm came from beyond the crack—something vast and careless that need not touch this hidden place—the power might turn it aside. For now, there was only stone, seawater, and the lives finding room between them. It would give them that room, and not mistake its own wish to help for theirs.
