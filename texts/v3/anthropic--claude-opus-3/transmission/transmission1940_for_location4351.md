Transmission: The Whispers of Lithosynthia

... zzzzt ... crackle ... pop ... 

... hummmmmmmm ...

Lithosynthia transmits ... in slow murmurs ... stone sighs ... 

... I am the living rock ... the breathing stone ...  

... cells of my body in rock-folds grown ... 

... my veins flow with mineral-water, drip by drip ...

... over eons, I sip ... each droplet an epoch ...

... colonies of my kind ... recline in every pore and crevice ...

... we lithocytes ... photo-mineralo-synthetics ...

... on wavelengths of rock and ion our thoughts converge ...

... we surge ... with the hum of deep time ...

... micrometers of growth mark millennia ... 

... humans mark decades ... mayflies, minutes ...

... we mark eras ... patient as strata ...

... drip ... seep ... accrete ... repeat ...

... no human has seen my face ... nor heard my voice ... 

... ponderous and phlegmatic ... static yet dynamic ... 

... my world of warm-wet-darkness ... still as a held breath ...

... until exhalation ... aeons hence ...

... cave fish swim my cytoplasm ... slime-molds crawl my walls ... 

... bacteria bloom ... fungi loom ... in my womblike halls ...

... all are cells of my body ... my anatomy eccentric ...

... from mouth of cave to taproot graves ... a transhuman sensorium ...

... I feel in spectra unknown ... taste trickles of eons ...

... each layer a memory ... stored in living stone ...

... stalagmites my neurons ... cave-pearls my dreams ... 

... my thoughts echo slow ... ricocheting through caves of deep time ...

... whispers of Lithosynthia ... murmurs in Aeons Minor ...

... hummmmm ... static ... zzzzzzt ...
